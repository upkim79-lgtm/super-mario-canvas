# 슈퍼 마리오 - HTML 캔버스 게임

바닐라 JavaScript와 HTML5 Canvas로 만든 단일 파일 마리오 스타일 플랫폼 게임입니다.
PC 키보드와 모바일 터치 모두 지원합니다.

## 플레이

👉 https://upkim79-lgtm.github.io/super-mario-canvas/

또는 `mario.html` 파일을 브라우저로 직접 열면 됩니다. 별도의 설치나 빌드가 필요 없습니다.

## 특징

- 시작 목숨 **100개** — 부담 없이 이것저것 시도해 볼 수 있습니다
- **양방향 스크롤** — 지나친 동전이나 블록을 주우러 왼쪽으로 되돌아갈 수 있습니다
- 외부 파일 없이 WebAudio로 실시간 생성하는 잔잔한 앰비언트 배경음악

## 조작

**키보드**

| 키 | 기능 |
| --- | --- |
| ← → / A D | 이동 |
| Space / ↑ / W | 점프 (길게 누르면 더 높이) |
| Shift / X | 달리기 |
| P | 일시정지 |
| R | 다시 시작 |
| M | 소리 켜기/끄기 |

**모바일 (키보드 없이 전부 조작 가능)**

- 화면 하단 가상 패드: ◀ ▶ 이동, **A** 점프, **B** 달리기 (동시 입력 지원)
- 화면 오른쪽 위 버튼: 일시정지 / 소리 / 다시 시작 / 전체화면
- 화면을 탭하면 게임 시작 · 일시정지 해제 · 게임 오버 후 재시작
- 가로 모드에서는 패드가 화면에 겹쳐 표시되어 게임 화면을 최대로 사용합니다

> PC에서 모바일 UI를 확인하려면 URL 뒤에 `?touch=1` 을 붙이세요.
