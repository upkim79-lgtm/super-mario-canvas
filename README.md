# 슈퍼 마리오 - HTML 캔버스 게임

바닐라 JavaScript와 HTML5 Canvas로 만든 단일 파일 마리오 스타일 플랫폼 게임입니다.
PC 키보드와 모바일 터치 모두 지원합니다.

## 플레이

👉 https://upkim79-lgtm.github.io/super-mario-canvas/

또는 `mario.html` 파일을 브라우저로 직접 열면 됩니다. 별도의 설치나 빌드가 필요 없습니다.

## 특징

- 시작 목숨 **100개** — 부담 없이 이것저것 시도해 볼 수 있습니다
- **양방향 스크롤** — 지나친 동전이나 블록을 주우러 왼쪽으로 되돌아갈 수 있습니다
- **파워업 3단계** — 버섯으로 커지고, 커진 상태에서 ? 블록을 치면 파이어플라워가 나와 불꽃을 쏠 수 있습니다 (피격 시 불꽃 → 큰 상태 → 작은 상태 → 사망)
- **거북이(쿠파)** — 밟으면 껍질이 남고, 껍질을 발로 차면 굴러가며 다른 적을 쓸어버립니다 (굴러오는 껍질에 맞으면 피해)
- **무적 스타** — ? 블록에서 나오는 스타를 먹으면 10초간 무적. 부딪히는 적을 그냥 쓸어버리고 배경음악이 빨라집니다
- **파이프 진입** — 워프 파이프(▼ 표시) 위에서 아래 방향키를 누르면 보너스 코인방으로
- 외부 파일 없이 WebAudio로 실시간 생성하는 칩튠 배경음악·효과음

## 조작

**키보드**

| 키 | 기능 |
| --- | --- |
| ← → / A D | 이동 |
| Space / ↑ / W | 점프 (길게 누르면 더 높이) |
| ↓ / S | 숙이기 · 파이프 진입 (공중에서는 빠른 낙하) |
| Shift / X | 달리기 · 불꽃 발사(불꽃 상태) |
| P | 일시정지 |
| R | 다시 시작 |
| M | 소리 켜기/끄기 |

**모바일 (키보드 없이 전부 조작 가능)**

- 화면 하단 가상 패드: **▲◀▼▶** 4방향 D패드 + **A** 점프, **B** 달리기 (동시 입력 지원)
- ▼ = 숙이기 / 파이프 진입, ▲ = 점프(A와 동일), **B** = 달리기 · 불꽃 발사
- 화면 오른쪽 위 버튼: 일시정지 / 소리 / 다시 시작 / 전체화면
- 화면을 탭하면 게임 시작 · 일시정지 해제 · 게임 오버 후 재시작
- 가로 모드에서는 패드가 화면에 겹쳐 표시되어 게임 화면을 최대로 사용합니다

> PC에서 모바일 UI를 확인하려면 URL 뒤에 `?touch=1` 을 붙이세요.
